# brazucafc.ca

Site do **Brazuca FC**. No momento, uma página estática de "em construção".

## Estrutura

- `index.html` — página inicial (Work In Progress)
- `assets/brazuca-wip.jpg` — arte principal (1402px, otimizada)
- `assets/brazuca-wip-800.jpg` — versão para telas menores
- `assets/favicon.svg` — ícone
- `Brazuca_WIP.png` — arte original (fonte, sem otimização)
- `CNAME` — domínio customizado para o GitHub Pages

## Rodar localmente

```bash
python3 -m http.server 8000
```

Depois abra http://localhost:8000

## Publicação

Hospedado no GitHub Pages a partir da branch `main` (raiz do repositório).
